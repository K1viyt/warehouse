# СЕКЦИЯ — карта функций для заказчика

Основной документ: **section-spec.drawio**. Дополнительные форматы: **section-spec.html** (интерактивный просмотр) и **section-spec.pdf** (9 страниц). **overview.png** — общая карта.

8 разделов, 50 функций. Зелёный — полностью готово; жёлтый — начато, но не завершено; красный — ещё не реализовано. Статус раздела определяется его функциями: все готовы — зелёный, все отсутствуют — красный, остальные сочетания — жёлтый.

Состояние реализации на 15.10.2026, основание — код ced61fb. Цвет отражает реализацию, а не отдельный результат независимой приёмки.

Заказчику предназначены только section-spec.* и overview.png. Технические контракты, тестовые матрицы и инструкции не включены в эту карту. Прежний технический документ сохранён отдельно как technical-spec.*; qa-results.csv остаётся рабочим файлом тестера.

В HTML-просмотре загрузка официального просмотрщика diagrams.net требует интернета. PDF и файл draw.io можно открыть локально.
