# СЕКЦИЯ — актуальные макеты Figma

Выгрузка от 15.10.2026 из [файла Figma](https://www.figma.com/design/fRy4i8gmJo8H882xNO2Mld).

- **section-design.fig** — оригинальный редактируемый файл, сохранённый командой Figma «Save local copy». Содержит слои и изображения.
- **section-design.pdf** — штатный экспорт всех 9 экранов из Figma, качество High, профиль sRGB.
- **png/** — изображения 9 экранов, полученные из этого PDF при 96 dpi для просмотра в GitHub.
- **manifest.json** — состав, порядок экранов и контрольные суммы SHA-256.

В этой версии уже есть фотографии склада с палетами и погрузчиком, крепежа и исправленного прямого чёрного самореза. Это статические макеты; работающие формы находятся в приложении.

Проверены целостность архива .fig, наличие 9 страниц PDF, открытие PNG и внешний вид всех 9 экранов. Повторный импорт .fig в новый файл Figma не выполнялся.
